## 📖 概要

**幕末風雲録：双極の蒼穹** は、慶応の日本を舞台にした **一人用デッキ構築型ローグライトカードゲーム** です。

『Slay the Spire』や『Balatro』のようなテンポの良いカードバトルに、幕末史の歴史的ジレンマを融合。1ランが約30〜50分で完結する本格的な長編構成（全3幕・各幕13〜14階層、全40ノード前後）となり、繰り返しプレイするたびに異なる奥深いデッキ構築体験が生まれます。

> **外部ライブラリ・プラグイン不要。** `index.html` をブラウザで開くだけで即プレイ可能です。

## 🎮 ゲームの特徴

### ⚔️ 2大陣営の選択
| | 🔴 薩長同盟（討幕派） | 🔵 幕府・会津藩（佐幕派） |
|---|---|---|
| **初期HP** | 75 | 85 |
| **初期資金** | 100 両 | 120 両 |
| **初期デッキ** | 基本カード2枚（示現流×1、見切り×1 ※志士カードなし） | 基本カード2枚（天然理心流×1、鉄壁×1 ※志士カードなし） |
| **プレイスタイル** | 攻撃・連鎖・コンボ | 防御・持久・反撃 |
| **代表志士** | 坂本龍馬・西郷隆盛・桂小五郎・高杉晋作 | 土方歳三・近藤勇・沖田総司・勝海舟 |
| **リスク** | 西洋借款による列強介入の急加速 | 家臣の寝返り（呪いカード混入） |

> **※初期デッキと志士カードの獲得について**：ゲーム開始時の初期デッキには志士カードは一切含まれず、基本技（Starter攻撃1枚、Starter防御1枚の計2枚）のみでスタートします。マップの最初に選択するコマ（Floor 0）は必ず**志士を入手できる歴史事件**となっており、プレイヤーは最初の歴史的決断を通じて志士をデッキに迎え入れて旅を開始します。

### ⚠️ 列強介入メーター（インペリアル・ゲージ）
- 西洋兵器の使用・列強密貿易（借款）によって **0% → 100%** へ上昇
- **100%に達すると「植民地化敗北」** — 戦闘状況に関わらず即ゲームオーバー
- 休息マスの「条約交渉」や特定イベント、一部志士カードで低下可能

### 🃏 多彩なカードと戦略
- **全108枚**のカード（討幕派50枚、佐幕派50枚、西洋兵器4枚、不平等条約呪い4枚）
- カードのレアリティ: Starter / Common / Uncommon / Rare / Legendary / Curse
- **全志士 史実コネクト・リンク (全177組・全志士網羅)**: すべての志士（全90名）に固有の史実コンボが存在。龍馬＋西郷【龍馬と西郷・天下の大鐘！】、勝海舟＋西郷【江戸城無血開城！】、松平容保＋近藤勇【会津守護の忠誠！】、伊藤博文＋井上馨【長州五傑の盟友！】、高杉晋作＋山県有朋【奇兵隊の師弟！】、土方歳三＋榎本武揚【五稜郭の誓い・蝦夷の夢！】、大久保利通＋岩倉具視【維新断行の盟友！】、坂本龍馬＋後藤象二郎【清風亭の盟約・大政奉還！】など、同一ターンに盟友を使用すると金色の絆が結ばれ、**専用の連鎖墨文字**とダイナミックな演出とともに強力なボーナス効果が発動
- **手札ホバー予測ガイドライン**: 手札の志士にカーソルを合わせると、コンボ対象となる手札のカードが金色に輝き、光線で結ばれて連携可能かを直感的に把握可能

### ✨ エフェクトと演出
- **🎴 敵側デッキ・伏せ手札＆カード公開（本格対面カードバトル）**: 戦場では敵武士も専用のデッキ（山札・手札・捨札）を所持。敵の手札は漆黒×金箔の和風家紋が描かれた「伏せ札」として並び、敵の手番になると使用カードが中央へ進出して**表向きに3Dフリップ公開**！ 技名（『虎徹・袈裟斬り』『抜き打ち』『不動の構え』等）と威力が明示されてから発動する、迫真の対面カードバトル体験
- **連鎖カウンター**: カードを連続使用すると「壱之連」「弐之連」「参之連」…と墨文字と飛沫がダイナミックに出現
- **墨飛沫・斬撃・火花エフェクト**: HTML5 Canvas によるリアルタイムパーティクル描画
- **Web Audio APIサウンド**: 外部音声ファイル不要。和太鼓・拍子木・居合斬撃・小銃発砲・呪詛警報などをリアルタイム合成

| 幕 | 舞台 | 階層数 | 最終ボス（討幕派） | 最終ボス（佐幕派） |
|---|---|---|---|---|
| 第一幕 | 京洛動乱（京都・伏見） | 14階層 ＋ 幕ボス | 近藤勇 | 桂小五郎 |
| 第二幕 | 東海道進撃（箱根） | 14階層 ＋ 幕ボス | 松平容保 | 西郷隆盛 |

**ノード種別**:
- 📜 **歴史事件**（**第一幕の最初の選択コマは志士を入手できる歴史事件が確定出現！** 池田屋事件・神戸海軍操練所・新選組結成・奇兵隊結成など）
- ⚔️ **戦場**（通常敵。※第二幕・終幕の最初の選択コマは戦場からスタート）
- 👹 **強敵**（岡田以蔵・芹沢鴨などの中盤・終盤の難敵）
- 🎁 **武器庫**（中盤フロアに眠る秘蔵の葛篭。強力な遺物や大量の軍資金を獲得）
- 💰 **洋行商人**（国内調達・列強密貿易/借款・不要札破棄）
- 🍵 **本陣休息**（茶屋・養生HP回復・条約交渉・カード削除）
- 🏯 **決戦大陣**（幕末の決戦・ボス戦）

### 💾 途中自動セーブ＆ワンクリック再開（Auto-Save / Continue）
- **完全自動保存**: ノード突入時、戦闘勝利後、歴史事件選択時、商人・休息利用時に進行状況を `localStorage` にシームレス自動保存。
- **安心の中断・再開**: ブラウザを誤って閉じたりリロードしても、タイトル画面の「📜 続きから再開」ボタンから直前の状態（陣営、HP、所持金、デッキ、マップ進行度）へ即座に復帰可能。
- **データ保護**: ゲーム進行中の新規ラン開始時には上書き確認ダイアログを表示。敗北またはクリア時にはセーブデータが自動消去され、常にクリーンな状態を維持。

## 🔊 サウンドシステム

画面シーンに応じた専用BGM楽曲（MP3）と、**Web Audio API** によるリアルタイム和風プロシージャル効果音のハイブリッド構成を採用しています。ヘッダーのボタン（狭小画面時はプルダウンメニュー）から、**「🎵 BGM」** と **「🔊 効果音」** をそれぞれ個別にON/OFF切り替え可能です。

### 🎵 BGMトラック構成

|---|---|---|

| マップ探索・各イベント | `Edge_of_the_Setting_Sun.mp3` | ループ再生（マップ復帰時自動再開） |
