## 🚀 プレイ方法

### 必要なもの
- モダンブラウザ（Chrome / Edge / Firefox / Safari 最新版推奨）
- **サーバー不要・インストール不要・外部依存ゼロ**（ライブラリ不使用）

> **`index.html` をブラウザで開くだけで即座にプレイ可能です。**

### 起動手順

```bash
# リポジトリをクローン
git clone https://github.com/rinevo/Bakumatsu.git

# index.html をブラウザで開く（ダブルクリックでも起動可能）
```

または **[GitHub Pages で今すぐプレイ](https://rinevo.github.io/Bakumatsu/)**（Webブラウザから直接遊べます）。

### 基本操作
| 操作 | 内容 |
|---|---|
| カードをクリック | カードをプレイ（文を消費して攻撃・防御・計略発動） |
| カードをホバー | コネクト・リンク（史実コンボ）予測ガイドラインを表示 |
| 「太刀を収める」ボタン | ターン終了（敵の行動ターンへ移行） |
| マップノードをクリック | 次に進むマス（事件・戦場・強敵・武器庫・商人・休息）を選択 |
| 「📜 帖（山札確認）」ボタン | 現在のデッキ・捨札・除外札を確認 |
| 「🎵 BGM」「🔊 効果音」ボタン | サウンドの個別ON/OFF切り替え（狭小画面時は「☰ メニュー」内） |

## 📖 作品概要

**『幕末風雲録：双極の蒼穹』** は、激動の幕末・慶応期を舞台にした **一人用デッキ構築型ローグライトカードゲーム** です。

『Slay the Spire』の洗練されたカード戦闘と、『Balatro』のようなダイナミックな連鎖・コンボ体験に、幕末史の史実ジレンマを融合。1ラン約30〜50分で完結する本格長編構成（全3幕・各幕13〜14階層、全40ノード前後）となっており、周回するたびに異なる奥深いデッキ構築が楽しめます。

## 🎮 主なゲームシステム（ハイライト）

### ⚔️ 2大陣営の選択
プレイヤーは旅立ちの際、**「🔴 薩長同盟（討幕派）」** または **「🔵 幕府・会津藩（佐幕派）」** を選択します。
初期デッキは志士カードを含まない基本技2枚のみから始まり、最初の歴史事件（Floor 0）で歴史的決断を下して志士をデッキに迎え入れます。

### 📜 全109件の歴史事件と因縁ルール
年代順（1842年〜明治初期）に発生する歴史事件で下した決断が、仲間の加入や世論の針を動かします。
史実に基づき、**敵対陣営の手によって討たれた志士（暗殺・処刑・戦死）は、仇敵陣営プレイ時には一切入手できない「歴史的因縁システム」**が組み込まれています。

### 🃏 全志士 史実コネクト・リンク（全233組コンボ）
登場するすべての志士（全101名・1志士1枚完全厳守）に固有の史実連携が存在。龍馬＋西郷【天下の大鐘】、勝海舟＋西郷【江戸城無血開城】、土方歳三＋近藤勇【誠の連帯】、松平容保＋萱野権兵衛【主家殉難・義の家老】、桂小五郎＋周布政之助【長州藩政の師弟】、立見尚文＋酒井玄蕃【雷神と鬼玄蕃】など、盟友を同一ターンに繰り出すことで金色の光線が結ばれ、専用墨文字演出とともに絶大な連携効果が発動します。手札ホバー時に連携可能カードを光で示す**予測ガイドライン機能**も搭載。

### 🎴 本格対面カードバトル（敵伏せ札＆3D公開）
敵武士も専用デッキ（手札・山札）を所持。敵の手札は漆黒×金箔の伏せ札として並び、敵の手番になると使用カードが中央に進出して**3Dフリップ回転で表向きに公開**。繰り出される技と威力を視覚的に捉えながら白熱の読み合いが楽しめます。

### ⚖️ 世論動乱（天下の大勢）システム
歴史事件の決断により、世論が **佐幕極限（-100%） ◀ 0% ▶ 討幕極限（+100%）** へと揺れ動きます。優勢時は攻撃力や資金ボーナスを得られますが、敵対陣営へ50%以上傾斜すると**「毎ターン手札-1枚」「敵剛力+4」「敵開幕シールド+20」**などの苛烈なペナルティが科されます。

### ⚠️ 列強介入メーター（インペリアル・ゲージ）
強力な西洋兵器（ミニエ銃・アームストロング砲）の使用や列強借款によりメーターが上昇。**100%に達すると戦闘の優劣に関わらず即座に「日本植民地化敗北」**となります。本陣休息マスでの条約交渉などでゲージを制御することが不可欠です。

### 💾 途中自動セーブ＆ワンクリック再開
ノード進入、戦闘勝利、商人、事件選択時に `localStorage` へ完全自動保存。誤ってブラウザを閉じても「📜 続きから再開」からいつでも直前の状態へ即座に復帰できます。

## 🛠️ 技術スタック

| 技術 | 用途 |
|---|---|
| **Vanilla HTML5** | UI構造・全画面レイアウト・ダイアログモーダル |
| **CSS3** | 和モダン×浮世絵風テーマ・3Dフリップアニメーション・レスポンシブデザイン |
| **Vanilla JavaScript (ES6+)** | クラスベースのゲームロジック・ステート管理（外部フレームワーク不使用） |
| **Web Audio API** | 和太鼓・拍子木・抜刀・大砲などのリアルタイムプロシージャル効果音合成 |
| **HTML5 Canvas (2D)** | 墨飛沫・斬撃・火花・コネクトリンク光線のリアルタイムパーティクル描画 |
| **SVG** | マップノード間の接続街道ライン描画 |

> **外部フレームワーク・外部ライブラリ・Node.jsビルドツール一切不使用**。Web標準技術のみで完結しています。
