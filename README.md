## 🚀 プレイ方法

### 必要なもの
- モダンブラウザ（Chrome / Edge / Firefox / Safari 最新版推奨）
- **サーバー不要・インストール不要・外部依存ゼロ**（ライブラリ不使用）

> **`index.html` をブラウザで開くだけで即座にプレイ可能です。**

### 起動手順

```bash
# リポジトリをクローン
git clone https://github.com/rinevo/Bakumatsu.git

# index.html をブラウザで開く（ダブルクリックでも起動可能）
```

または **[GitHub Pages で今すぐプレイ](https://rinevo.github.io/Bakumatsu/)**（Webブラウザから直接遊べます）。

### 基本操作
| 操作 | 内容 |
|---|---|
| カードをクリック | カードをプレイ（文を消費して攻撃・防御・計略発動） |
| カードをホバー | コネクト・リンク（史実コンボ）予測ガイドラインを表示 |
| 「太刀を収める」ボタン | ターン終了（敵の行動ターンへ移行） |
| マップノードをクリック | 次に進むマス（事件・戦場・強敵・武器庫・商人・休息）を選択 |
| 「📜 帖（山札確認）」ボタン | 現在のデッキ・捨札・除外札を確認（各カードクリックで拡大詳細表示） |
| 「🎵 BGM」「🔊 効果音」ボタン | サウンドの個別ON/OFF切り替え（狭小画面時は「☰ メニュー」内） |

## 📖 作品概要

**『幕末風雲録：双極の蒼穹』** は、激動の幕末・慶応期を舞台にした **一人用デッキ構築型ローグライトカードゲーム** です。

『Slay the Spire』の洗練されたカード戦闘と、『Balatro』のようなダイナミックな連鎖・コンボ体験に、幕末史の史実ジレンマを融合。1ラン約30〜50分で完結する本格長編構成（全3幕・各幕13〜14階層、全40ノード前後）となっており、周回するたびに異なる奥深いデッキ構築が楽しめます。

## 🎮 主なゲームシステム（ハイライト）

### ⚔️ 2大陣営の選択
プレイヤーは旅立ちの際、**「🔴 薩長同盟（討幕派）」** または **「🔵 幕府・会津藩（佐幕派）」** を選択します。
初期デッキは志士カードを含まない基本技2枚のみから始まり、最初の歴史事件（Floor 0）で歴史的決断を下して志士をデッキに迎え入れます。

### 📜 全131件の歴史事件と天命判定システム
年代順（1842年〜1869年5月・箱館戦争終結）に発生する歴史事件では、提示された選択肢の「史実成功見込」を吟味して決断。決断後、太鼓と八卦による**「天命の審判（運命ロール）」**が発生します。
- **🏆 大成功（大業成就）**: 志士確定獲得＋元のHP被ダメージ無効化（無傷達成）＋軍資金+25両＋次戦剛力+3＋世論有利+5%。
- **⭕ 成功（史実貫徹）**: 志士確定獲得＋史実通りの通常効果・代償適用。
- **☠️ 失敗（作戦蹉跌）**: **志士カードは入手不可！** 深手の痛手（HP 15ダメージ または元の被ダメージ）＋軍資金散逸（-15両）＋世論悪化。
また、敵対陣営の手によって討たれた志士（暗殺・処刑・戦死）は仇敵陣営プレイ時には一切入手できない**「歴史的因縁システム」**も組み込まれています。

### 🏮 志士カード影響力・英傑結束システム
デッキに従えた志士たちは単なる手札にとどまらず、ゲーム全編に絶大な影響を及ぼします。
- **戦闘開幕アライアンス**: 「松下村塾（初手ドロー+1/剛力+2）」「新選組（敵脱力2/開幕防+8）」「薩摩示現（敵防半減/剛力+2）」「土佐海援（初手気力4文スタート）」など、盟友2名以上でパッシブ発動。
- **歴史事件助勢・限定ルート**: 史実に関わりの深い志士を所持していると被ダメージ半減や追加資金ボーナスが自動発動し、特定志士限定の奇策選択肢や鍵付きマスが解放されます。

### 🃏 全志士 史実コネクト・リンク（全259組コンボ）
登場するすべての志士（全116名・1志士1枚完全厳守）に固有の史実連携が存在。龍馬＋西郷【天下の大鐘】、勝海舟＋西郷【江戸城無血開城】、土方歳三＋近藤勇【誠の連帯】、松平容保＋萱野権兵衛【主家殉難・義の家老】、桂小五郎＋周布政之助【長州藩政の師弟】、立見尚文＋酒井玄蕃【雷神と鬼玄蕃】など、盟友を同一ターンに繰り出すことで金色の光線が結ばれ、専用墨文字演出とともに絶大な連携効果が発動します。手札ホバー時に連携可能カードを光で示す**予測ガイドライン機能**も搭載。

### 🎴 本格対面カードバトル（敵伏せ札＆シールドゲージ視覚化）
敵武士も専用デッキ（手札・山札）を所持。敵の手札は漆黒×金箔の伏せ札として並び、敵の手番になると使用カードが中央に進出して**3Dフリップ回転で表向きに公開**。
さらに戦闘中央帯の**プレイヤーHP＆シールドゲージ**と、敵頭上の**シールド（防具）ゲージバー**により、激しい攻防の推移を直感的に把握できます。

### ⚖️ 世論動乱（天下の大勢）システム
歴史事件の決断や本陣休息での世論工作により、世論が **佐幕極限（-100%） ◀ 0% ▶ 討幕極限（+100%）** へと揺れ動きます。優勢時は攻撃力や資金ボーナスを得られますが、敵対陣営へ50%以上傾斜すると**「毎ターン手札-1枚」「敵剛力+4」「敵開幕シールド+20」**などの苛烈なペナルティが科されます。

### ⚠️ 列強介入メーター（インペリアル・ゲージ）
強力な西洋兵器（ミニエ銃・アームストロング砲）の使用や列強借款によりメーターが上昇。**100%に達すると戦闘の優劣に関わらず即座に「日本植民地化敗北」**となります。本陣休息マスでの「条約交渉と世論工作（列強-15%／自軍有利世論10%）」などでゲージを制御することが不可欠です。

### 💰 洋行商人（資金消費必須・撤退仕様）＆ 多彩なHP回復
洋行商人では軍資金の消費が必須となっており、何も購入・消費しない場合は街道を進めず元のマスへ引き返します（撤退）。商人での長崎蘭方医による応急手当（HP30%回復）、本陣休息（養生35%回復/煙管で50%）、戦闘勝利時の残存シールドHP還元（最大5）、中立道具カードなど、多彩な生存戦略が楽しめます。

### 💾 途中自動セーブ＆ワンクリック再開
ノード進入、戦闘勝利、商人、事件選択時に `localStorage` へ完全自動保存。誤ってブラウザを閉じても「📜 続きから再開」からいつでも直前の状態へ即座に復帰できます。
